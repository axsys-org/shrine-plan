# Cell experiments

These projects exercise Shrine through its MCP mount. Each experiment keeps its
inputs, scripts, validation evidence and runtime boundaries together.

- [Branchmap](branchmap/README.md): seven public prediction markets mapped to
  event contexts, predicates, outcomes and canonical conditional verses, with
  native query cells and a simulated asset controller.

The [native Branchmap exchange](../mounts/branchmap/README.md) continues the
prediction-market experiment with Foil accounting and a Grove/Goo frontend.
