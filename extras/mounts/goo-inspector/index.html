Scope and limits

Local selection and deck switching use the existing Goo session. No writes are submitted here. Previews are read-only; interactive views open separately in the explorer. Synthetic values are bounded previews, not exact-value exports.

Goo's collection adapter supports at most 64 physical children of a record. Broad namespace roots, structural paths and larger populations use the existing debugger's paginated navigation links. Refresh explicitly observes changes. Changing the browsed path creates a new local workspace. Pane-bearing views are listed but not recursively mounted.
