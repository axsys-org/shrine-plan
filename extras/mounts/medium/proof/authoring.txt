GROVE NATIVE CONTRACT:

  function from row[myth] to either[str unit]. Check the exact required input

  missing values instead of silently interpreting them as zero or an empty string.
- Required declaration `realize` exports a native grove_realization wrapping Foil:
    | grove_realization
    \ inputs=row[myth] current=myth
    ^ myth
  It initializes missing local values and derives outputs from native input records.
  Inputs are in exactly the order of the edit.inputs array. `current` is prior data.
  The wrapped function returns a myth of pails. Preserve prior user values. Do not replace them with defaults
  on each recomputation. Derivations must recompute from inputs rather than freeze

EXACT SYNTAX REFERENCE (replace /0x11/gov/medium/EXAMPLE with actual code_root):
#import lede=sys/lede
#import text=lib/grove/types/text

amount =
  @slot

number =
  @type
  ! foil
  nat
  + read
    \ value=pail
    ^ maybe[number]
    ?> wrapped=pails/n value .none
    | ./some wrapped.n
  + write
    \ value=number
    ^ pail
    | pails/n value
  + contract
    ^ curb
    | curb/of_type (^ pails/n)

account =
  @role
  lede: text
  %/amount: %/number

accepts =
  ! foil
  | grove_binding_contract
  \ inputs=row[myth]
  ^ either[str unit]
  ? !(eq inputs.len 0) (./err "This balance has no input positions.")
  | ./ok []

realize =
  ! foil
  | grove_realization
  \ inputs=row[myth] current=myth
  ^ myth
  = key=path [($x 17) 'gov 'medium 'EXAMPLE 'amount]
    amount (current.nat_at(key 0))
  | current.put(['sys 'lede] (pails/t "Balance")).put(key (pails/n amount))

add =
  @action
  #on ; %/account
  ! foil
  \ card=%/account
  ^ %/account
  | card.set_amount(card.amount.inc)

surface =
  @view
  #on ; %/account
  #for ; /sys/slot/detail
  card => {
    col("identity") {
      show(card.lede, '/sys/slot/title)
      number(card.amount, "value")
    }
    group(on = card, action = %/add) {
      action("Add one")
    }
  }

A native text editor can be in that same view:
  group(on = card, action = .poke, myth = {
    '/sys/lede = .input(card.lede)
  }) {
    input('/sys/lede)
    action("Rename")
  }

FOIL INDENTATION (significant; lifted from the compiled medium/compute):
The name/value columns under an = matter. If an = is in column 2, its local
name starts in column 4. A MULTILINE VALUE starts in column 6, not column 4.
The function body's ^, =, ?, and | are PEERS of its backslash, not children.
This is the exact shape (spaces shown by indentation):
  = cell
      \ i=nat
      ^ str
      = x (mod i 16)
        y (div i 16)
      | str/cat_all [(nat/show x) "," (nat/show y)]
  = cells (row/range 0 144).map(cell)
  | str/cat_all cells
Do not indent the lambda only two spaces under =; that starts another binding
pattern rather than the value. The same rule applies to named loops:
  = body=str
      % i=nat 0 out=str ""
      ? (eq i 144) out
      = part (nat/show i)
      | _ i.inc out.cat(part)
  | body
Use prefix (mod a b), (add a b), (mul a b), (div a b). Do not invent infix %.
Never enumerate an integer range: row/range 0 144 is already native.

SHOW IS DIFFERENT FROM TEXT: show(value, slot) performs Grove renderer lookup; its slot must be an exact native path (e.g. show(card.lede, '/sys/slot/title)). Do not give show a string role. Ordinary text/number/image accept visual role strings. For a plain text field, text(card.lede, "title") works without renderer lookup.
