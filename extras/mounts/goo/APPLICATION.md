# Inspector, CLI and HTTP application

The application uses the native Foil compiler and renderer. The retained Haskell
component still contains only Rex and the narrow Goo Rex formatting adapter.
Python supplies process framing, UUID entropy, argument/file I/O and HTTP serving.
There is no Haskell semantic or application sidecar.

## Running

From the parent repository:

```sh
extras/mounts/goo/bin/goo build
printf 'text("Hello")' | extras/mounts/goo/bin/goo passes
extras/mounts/goo/bin/goo html --width 375.25 --text-scale 2 --rtl extras/mounts/goo/examples/profile.goo
extras/mounts/goo/bin/goo serve --port 8000
```

Invoking the executable without a command defaults to `serve`. The application default view is
`/sys/slots/summary`; the earlier test adapter keeps its `/full` default.
`passes` stops after semantic lowering and does not run ASCII measurement.
`html` emits a static document. Inspector preview documents use the original
script-disabled iframe shell, with an escaped JSON compiler message; they are a
separate view from exported documents.

HTTP uses four preloaded execution workers, with one request per leased worker.
Every call supplies its complete input; UUID allocation and Goo caches remain
request-local. Workers recycle after 64 calls and are discarded after a protocol
failure or process exit. The immutable generation check still requires rebuilding
and restarting after source changes. Version polling and static assets do not
wait for a compilation worker.

Execution results use indexed UTF-8 JSON frames written directly to stdout;
diagnostics stay on stderr. Strings larger than 8 KiB are passed through private
data files beneath each worker’s restricted file root, then removed after the
call. Filenames are generated by the host; contents are never executed. Smaller
inputs use balanced assembly. The native application JSON encoder and HTML
escaper avoid repeatedly copying growing inspector strings. Display diffing
uses persistent edit histories and linear pure-insertion/deletion paths. These
changes address observed integration bottlenecks; the comparative latency and
memory acceptance work remains item 35.

Builds are immutable local publications. A changed source input requires a new
build. The standalone sources and production inputs now live in `extras/mounts/goo`;
installation outside the parent runtime checkout remains roadmap item 34.

## Native boundaries

- `display.foil` consumes typed pass results, combines sugar normalization and
  UUID allocation into the original five application stages, and constructs Rex
  trees. It adds metric, layout and adjacency-trace projections from a validated
  measurement result.
- Stable `node-N` aliases apply only to identity fields in diff output. Actual
  snapshot output, compiler messages, measurements and HTML retain runtime IDs.
  Payloads and config strings are never aliased.
- `production.foil` keeps compiler results and snapshots in the worker. Only
  compact Rex batches cross the retained printer boundary; they preserve all nine
  forms, full spans, colors, shapes and payloads. Both actual and diff projections
  use the same shared printer. The host returns printed strings to that request's
  continuation; successful completion clears it, and failures discard the worker.
- `views.foil` implements pass cards, shortest-edit-script diffs, context markers,
  diagnostics, crash views and preview documents. `pages.foil` contains the
  inspector/gallery markup and native escaping/assembly of dynamic content.
- `/lower` compiles fresh source. `/layout` validates semantic trees and produces
  native measurements, explicit text lines and HTML. `/rendered` validates a
  measurement result before producing its three display snapshots. No HTTP
  endpoint accepts caller-created compiler snapshots or prepared render trees.
- The original inspector JavaScript, fonts, CSS and examples are served from their
  existing URLs. Saves write only beneath the selected `GOO_ROOT/examples`.
  Assets are read fresh; version polling reports boot and modification stamps.

Display numbers use shortest round-tripping binary64 decimals; JSON transport
continues to preserve finite binary64 values exactly. CSS numbers include the
`.0` spelling expected by the existing HTTP integration check. Unicode measurement
remains outside the agreed scope: non-ASCII text produces the existing ASCII
error. Counting characters for the inspector's long-line wrapping does not add a
Unicode measurement backend.

## Reproducing validation

```sh
bash goo/scripts/porting/build-application-oracle.sh
python3 goo/scripts/porting/check-application.py --workers 2
python3 goo/scripts/porting/check-application-cli.py
python3 goo/scripts/porting/check-application-workers.py
python3 goo/scripts/porting/check-application-escaping.py
python3 goo/scripts/porting/check-application-large.py
# With a replacement server running against an isolated GOO_ROOT:
python3 goo/test/http-layout.py http://localhost:8000
python3 goo/scripts/porting/check-application-http.py http://localhost:8000
```

The application oracle is test-only and imports the unchanged Haskell views.
Its real UUIDs are supplied to the native test invocation, allowing exact snapshot
comparison without replacing arbitrary strings. HTML comparison parses JSON
script contents and preserves ordinary text, classes and attributes. Snapshot
text, summaries, stage order and diff output are compared exactly.

Create a fresh test root with
`python3 goo/scripts/porting/prepare-application-root.py /tmp/goo-u-isolated`
(the directory must be empty). For the live browser lifecycle test, run
`python3 goo/scripts/porting/application-browser-server.py /tmp/goo-u-isolated 8799`,
open `http://localhost:8799/_u/harness`, and press
**Run live endpoint checks**. It serves the real replacement endpoints and only
delays selected layout responses. It tests both ordinary fetch cancellation and
the revision guard when cancellation is deliberately ignored. The resulting
report is written to `.build/application-browser-results.json`.

The HTTP suite saves a disposable `gate-u-save-test` example. Always use a copied
root for integration tests; never run it against frozen reference inputs.

HTML escaping matches Blaze's removal of nonprinting C0 characters, preserving
tab, LF and CR. The application escaping regression checks every supported C0
character, literal escapes and HTML closing tags. The inherited Foil transport
rejects NUL strings; this chunk does not change that string contract.

The first [performance pass](../../../goo/porting/perf-pass-01/README.md) records warm
inspection timings against the Haskell oracle, before/after native measurements,
and sampled memory. It is not the full item-35 acceptance workload.

Static SSR never constructs inspector snapshots. It returns length-delimited raw
UTF-8 HTML with small status/diagnostic metadata; the HTML is not JSON-escaped on
the internal wire. Inspector endpoints retain their browser-facing JSON API.
Examples and editable inspector assets remain live files and do not require a
compiler rebuild after saves. Fonts and generated rule/metric inputs remain
verified build dependencies.
