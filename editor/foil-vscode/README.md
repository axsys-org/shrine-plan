# Foil Language Support for VS Code

Editor support for the Foil surface language used by Shrine/PLAN.

Features:

- automatic language detection for `*.foil`
- highlighting for declarations, runes, imports, tags, comments, numbers,
  binders, pattern arms, member access, and delimiters
- apostrophe line comments (`'  comment`)
- bracket matching and auto-closing
- two-space indentation after declaration headers

The extension has no runtime dependencies or build step. To install it from
this repository, copy this directory to your VS Code extensions directory and
reload VS Code.
